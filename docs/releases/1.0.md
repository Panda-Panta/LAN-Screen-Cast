首次 GitHub 发布 **Release 1.0**（标签 `v1.0`），软件版本 **1.0.0**。

- Windows 10/11 x64 广播端，支持整个屏幕或软件 / 游戏窗口，同时提供网页观看链接、二维码和 RTMP 播放地址，直接复制即可分享。
- 系统声音和麦克风均可独立开启，支持混音、音量调节和麦克风静音；系统声音采集整台电脑的默认输出。
- 新配置默认网页 **HEVC 优先**，RTMP 默认 **HEVC + NVIDIA NVENC 优先**，不可用时尝试其他可用编码路径；保留 H.264、仅硬件和软件选项。网页硬件编码由 Chromium / 驱动决定。
- 自动保存设置；已有编码与加速偏好继续保留。二级路由器可查询 WAN 地址并生成一级网络观看地址，实际端口转发仍需手动设置。

下载以下任一 Windows x64 包：

- [LAN-Screen-Cast-1.0.0-win-x64.exe](https://github.com/Panda-Panta/LAN-Screen-Cast/releases/download/v1.0/LAN-Screen-Cast-1.0.0-win-x64.exe)：单文件便携程序，双击启动，首次运行先解压运行库。
- [LAN-Screen-Cast-1.0.0-win-x64.zip](https://github.com/Panda-Panta/LAN-Screen-Cast/releases/download/v1.0/LAN-Screen-Cast-1.0.0-win-x64.zip)：完整解压后运行 `LAN Screen Cast.exe`。

选择网卡和画面，按需打开声音，点击“开始广播”，再复制网页或 RTMP 地址。**HEVC 播放器必须支持 Enhanced RTMP**，具体 PotPlayer / VLC 版本需实际确认；兼容性优先时可改为 H.264。校园网与端口转发见[网络指南](https://github.com/Panda-Panta/LAN-Screen-Cast/blob/v1.0/docs/network-guide.md)。

按 **100 Mbps 上下行、1–5 台观看设备**进行配置预算，默认每台 6 Mbps；网页和 RTMP 共用观看人数上限。这是设计预算，实际性能受设备、网络和播放器缓存影响。

本轮静音验收已通过：**282 项 Node 测试、67 项语法检查，源码与打包目录各 22 项桌面检查**。单文件便携程序在声音关闭时，以默认 HEVC / `hevc_nvenc` 硬件编码，通过 Enhanced RTMP 实际解码 3 帧，复制与停止检查通过；ZIP CRC、制品哈希、154 个原生资源及 34 个生产文件核对通过。

**音频复验未完成**：本轮系统声音和 RTMP 双输入混音的四组复验已停止，当前打包版未通过完整音频运行验收，详情见[验证记录](https://github.com/Panda-Panta/LAN-Screen-Cast/blob/v1.0/docs/verification.md)。未验证校园网跨 NAT、物理多机、100 Mbps 限速压力及端到端延迟。

下载文件的 SHA256 见附件 `SHA256SUMS.txt`，清单包含 `LAN-Screen-Cast-1.0.0-win-x64.exe` 和 `LAN-Screen-Cast-1.0.0-win-x64.zip` 两项；制品核对摘要见 `release-verification.json`。
