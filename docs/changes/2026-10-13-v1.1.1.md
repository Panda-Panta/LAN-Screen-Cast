# 1.1.1 增量计划：UPnP 发现响应兼容性修复

用户随后要求接入系统声音，本修复并入 [1.2 系统声音增量](2026-10-13-v1.2.md) 交付；1.1.1 是本地验证阶段版本，不单独发布便携包。

## 复现与目标

用户使用中兴巡天 AX3000，确认 UPnP 已开启。1.1.0 的 `discoverRouterWan({host})` 在普通 Windows 进程复现原提示：默认网关未响应 UPnP 发现，NAT-PMP 未返回地址。独立只读 UDP 探测收到同一默认网关的标准 SSDP 响应，含空 `EXT:`；旧解析器在进入 HTTP 查询前丢弃该响应。另一个可独立复现的兼容问题是拒绝 UPnP 1.1 标准的带点号字段名。

目标：按 HTTP 字段名 token 语法读取 SSDP 响应，允许标准空字段值；保持默认网关来源限制、ST 和 LOCATION 校验、重复字段拒绝、HTTP 本地目标边界、只读 SOAP / NAT-PMP、超时与取消。公开接口和用户设置格式保持兼容。

交付时移除固定的便携版临时解压目录，沿用 electron-builder 为每次构建生成的目录名，避免正在运行的 1.1.0 与修正版覆盖同一运行目录。保持原 userData 和隔离测试目录。当前真实路由器描述自报 ZTE / ZXHN E2631，提供 WANIPConnection:1 查询服务。

不增加自动端口映射、路由器管理登录、端口扫描或防火墙改动。UDP 范围继续默认 50000–50100；用户可设至少 32 个端口，外部 / 内部范围必须相同。地址读取成功不能作为真实跨 NAT 观看成功的证据。

## 文件归属与顺序

| 所有者 | 范围 | 验收 |
| --- | --- | --- |
| 主 agent | `src/router-discovery.js`、版本、计划 / 使用说明 / 验证记录、构建与交付 | 修复标准报文解析；原真实网关查询复测；所有桌面检查串行使用隔离 userData；保留旧便携 EXE / ZIP |
| upnp_compat_review 子 agent | `tests/router-discovery.test.js` | 先独立复现空 EXT 和 UPnP 1.1 字段名失败，再添加真实本机 UDP / HTTP 回归及重复 / 无效字段拒绝检查；不访问真实路由器，不运行桌面检查 |

顺序：失败回归 → 最小解析修复 → 原网关查询 → Node / 语法与必要桌面回归 → 独立审查 → 1.2.0 合并构建与打包程序验证 → ZIP CRC / 源码与 ASAR 哈希检查。
