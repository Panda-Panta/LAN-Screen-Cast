# 1.1 增量计划：路由器地址、麦克风、自动保存及 HEVC

## 范围与验收

| ID | 新行为 | 验收 | 状态 |
| --- | --- | --- | --- |
| WAN-1 | 从所选网卡查找二级路由器网关，通过只读 UPnP IGD / NAT-PMP 查询 WAN IPv4 | 本地真实协议夹具；拒绝重定向、外部 URL、超限响应；不发送端口映射操作 | 模块通过 |
| WAN-2 | 自动模式每 30 秒重新读取；WAN 改变时刷新当前邀请、Host / Origin 白名单及后续 ICE 候选 | 旧地址失效、新地址获准、同一次广播令牌与 PIN 保持；不支持时保留手动地址 | 模块及桌面夹具通过 |
| MIC-1 | 初始被动读取；用户启用或刷新时申请权限并在枚举后释放探测轨道；保存设备偏好 | 隐藏标签、拔插、取消和迟到权限响应回归；本机真实枚举与启用 | 模块及实机通过 |
| PREF-1 | 修改设置后 250 ms 自动保存；正常关闭前刷新最新值；原子写入、按序保存 | 未开始广播也保存；快速修改后直接关闭再打开恢复；损坏旧文件安全回退 | 模块及桌面通过 |
| CODEC-1 | HEVC / H.265 优先，能力不支持或接收方不接受时回落；显示每台实际编码 | 真实 H.265 发送帧与接收解码帧；不支持 H.265 的接收端仍能解码并显示回落 | 模块及实机通过 |

用户确认此前麦克风报错已恢复；本次处理枚举、保存与错误反馈的稳健性，不把旧报错认定为已复现的持续故障。

保持屏幕 / 窗口选择、可选麦克风、五观看者预算、邀请导入 / 二维码 / `.url`、可信 IPC、停止 / 取消 / 重连行为。配置增加 `autoRouterAddress`（默认 true）、`networkName`、`sourceType`，允许 `codec=HEVC`。旧配置用默认值补齐；保存屏幕 / 窗口类别而不保存临时窗口 ID，重启后仍由用户选择具体画面。用户配置位于原应用 userData，测试均使用隔离目录。

自动读取不能阻止 DHCP 更新，不能把已发送的旧链接变成永久链接；地址改变后需要重新分享。没有自动修改路由器 / 防火墙、云服务、DDNS、TURN、RTSP 或系统音频。校园网用户隔离和真实跨 NAT 连通性仍需现场验证。

## 结构、契约与并行归属

| 所有者 | 文件 | 接口与依赖 |
| --- | --- | --- |
| router_auto 子 agent | `router-discovery.js` 及测试 | `discoverRouterWan({host,signal})`；返回 supported、WAN、gateway、method、message；选定网卡限定只读发现 |
| microphone_fix 子 agent | `microphone-controller.mjs` 及测试 | passive / permission refresh、preferredId、cancel / dispose；独占探测轨道并清理 |
| autosave 子 agent | `settings-autosave.mjs`、`settings-store.js` 及测试 | UI debounce / flush → 可信 IPC → 校验 → 顺序原子写入；关闭 handshake |
| hevc 子 agent | `shared/rtc.js`、`host-media.js` 及相关测试 | 能力 / 偏好 / 协商 / 实际编码分层；保留重传 codec；异步结果检查 peer generation |
| 主 agent | main / preload / config / GUI / share、路由地址控制器、服务动态更新、脚本、文档、版本、release | 统一装配合同、桌面检查和产物交付 |
| 独立审查 agent | 只读相关源码、计划与测试 | 核对需求、权限边界、生命周期、兼容性及验收缺口；不给尚未验证项盖章 |

依赖顺序：四个独立 helper 同时开发 → 主 agent 装配固定 IPC / 配置 / 状态 → Node 集成 → 串行真实桌面检查 → 独立审查修复 → 构建 → 打包程序检查 → ZIP / 源码一致性 / SHA256 → 交付。子 agent 不同时运行桌面测试，不修改彼此或主 agent 的文件。

持久化读写与广播启动校验分离：可保存暂未完成的 WAN 草稿和旧网卡地址；真正开始广播必须匹配当前网卡和完整转发配置。主进程只接受可信本地广播页及主 frame 的固定 IPC。关窗首先停止广播，再等渲染器刷新设置和主进程写队列；超时也停止媒体。自动 WAN 更新保留会话身份，旧异步查询不能修改后来会话。
