## 1.2 UPnP 实机与交付边界

修复后原 API、1.1.1 本地阶段 GUI，以及 1.2.0 源码 / 实际打包目录生产 GUI 均成功读取真实 WAN IPv4；源码与打包目录各自的自动及“立即读取地址”两次通过 UPnP。1.1.1 没有单独交付，修复并入 1.2.0。只读实机记录保留于 `.cache/router-diagnosis/`、`test-results/router-wan-gui.json` / `packaged-router-wan-gui.json`；私人网络地址不写入发布摘要。读取成功不证明校园网跨 NAT 已可观看，软件仍不创建端口映射。

系统声音采集整台电脑的默认输出，包含所选窗口之外的应用。未执行实际校园网跨 NAT、五台物理设备、100 Mbps 限速压力、手机、真人语音远端收听、具体游戏 / 独占全屏、其他 GPU / 电脑及端到端延迟测量。频谱和同机媒体证明不能替代这些现场验证。
